# Health Monitoring & Tracker

A simple, responsive health information website for everyday checkups, common viral illnesses, and finding care.

## Features

- General information about flu, COVID-19, dengue, common colds, viral stomach bugs, and RSV
- Adult reference ranges for blood pressure, temperature, resting pulse, and oxygen saturation
- Guidance on warning signs that may need urgent medical attention
- Sample government and private hospital listings
- A demo doctor appointment form
- Responsive layout built with HTML and CSS; no JavaScript

## Run locally

Open `outputs/index.html` in a web browser. The stylesheet is linked locally at `outputs/styles.css`.

## Notes

Health information is general guidance and does not replace advice from a qualified health professional. Hospital entries are examples and should be confirmed locally. The appointment form uses a placeholder email address and is not connected to an appointment service.
